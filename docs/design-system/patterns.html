Design System v0

The visual language, made literal.

This page renders every token, every component, and every pattern we have established. Read it in order. Copy from it as you build. If you find a pattern that is not in here, add it.

Foundations

Tokens.

The atoms of the system. Everything else is built from these. Tokens live in packages/design-tokens and are consumed by Tailwind, the application, and (eventually) Figma.

Colour

Ten brand tokens plus three functional. Used with discipline. Moss is the primary. Cream is the canvas. Terracotta is the accent. Charcoal is the body text. Everything else is supporting.

Motion

Restrained durations. Standard easing. All animations respect prefers-reduced-motion.

/* Durations */ --duration-instant: 100ms; /* tooltip open, click feedback */ --duration-quick: 200ms; /* hover state, focus ring */ --duration-standard: 300ms; /* most transitions */ --duration-slow: 600ms; /* drawer, modal open */ --duration-hero: 800ms; /* hero load fade-up */ /* Easing */ --easing-standard: cubic-bezier(0.4, 0, 0.2, 1); --easing-ease: ease;
Building blocks

Components.

Reusable units. Each has a stable name, a clear purpose, and a documented set of states. Built once, imported everywhere. Figma-aligned naming uses the Component/Variant/State pattern.

Button

Three variants: Primary (moss), Secondary (outlined moss), Ghost (text only). Three sizes: Small, Default, Large. Pill-shaped throughout. Buttons always carry white-space: nowrap so labels do not break.

Stable
Button/Primary, Button/Secondary, Button/Ghost
Variants
Sizes
States
<Button variant="primary" size="large"> Book a call </Button> <Button variant="ghost" href="/how-it-works"> See how it works → </Button>

Eyebrow

A small uppercase letter-spaced label that sits above headings. The audience signal: tells the reader what kind of content follows. On dark sections it uses terracotta-light instead of stone.

Stable
Eyebrow/Default, Eyebrow/OnDark
Default (on cream) For families with a parent who lives alone
On dark (moss background) How it works

FAQItem

Native HTML <details>/<summary>. The + icon rotates 45 degrees to become an × when opened. Pure CSS, no JavaScript. Keyboard-accessible by default.

Stable
FAQItem/Default
Will it always be the same companion?
Yes. That is the point. If your companion is unwell or on holiday, we propose a familiar back-up from the same area and tell you in advance.
Do you provide personal care?
No. We are not a care agency. If your mum or dad needs help with washing, dressing, toileting, or medication, we will recommend a regulated home-care agency we trust.
Can I cancel any time?
Yes. Pause or cancel in one click in your account. No phone call. No retention conversation. No guilt.

FormField

Label above, input below, optional hint between, optional error below. Sage border by default; moss on focus; alert on error. Designed to be obvious and forgiving.

Banner

A bordered notice. Four variants tied to the functional colour tokens. Used for system messages, draft notices, payment notices, error states. Always carries enough copy to act on; never just an icon.

Compositions

Patterns.

How components combine into recognisable page-level moments. Each pattern is named, used in multiple places, and has a documented structure.

Section

The page-level container. Three background variants create the cream / moss / cream-deep rhythm that gives the marketing site its editorial pacing. Section padding scales with the viewport.

Stable
Section/Cream, Section/Moss, Section/CreamDeep
Three variants
On cream

Default section.

On moss

Dark section. Used once per page maximum.

On cream deep

Alternate cream. Creates rhythm.

<Section background="cream"> <Container>...</Container> </Section> <Section background="moss"> // Once per page maximum. The visually strongest beat. </Section>

Hero

Asymmetric two-column on desktop, stacked on mobile. Eyebrow + headline + body + two CTAs + reassurance line on the left. Portrait card with overlapping quote on the right. The italic resolution in the headline is the brand promise.

TrustStrip

Horizontal list of brief trust signals. Sits as a band between the hero and the first long-form beat. Each item is prefixed with a small moss dot, never an icon. Wraps onto multiple lines without breaking visual rhythm.

FounderNote

Centred Fraunces in moss, with terracotta italic emphases for the key turns of the sentence. The brand's most emotionally important moment. Signed with a real human name and role. Max 60 characters per line.

Stable
FounderNote/Default

We started this company because we watched our own families navigate the gap between regulated home-care and nothing at all. So we built what was missing.

Bassey Eyo, Founder, Manchester

A note on this page

Live document.

This page is the source of truth for the visual language. It lives at /styleguide in the application, renders the same tokens that production uses, and updates whenever the tokens or components change.

If you spot a pattern in production that is not in here, add it. If you change a token, change it here too. Drift is the enemy of design systems.
